Conceptos básicos

¿Qué es una página web?

Una página web es un documento digital que puede contener texto, imágenes, enlaces, tablas, formularios, audio y video. Normalmente se visualiza mediante un navegador como Chrome, Firefox o Edge.

¿Cómo funciona una página web?

El usuario escribe una dirección o selecciona un enlace. El navegador solicita el recurso a un servidor web, el servidor responde y el navegador interpreta el código HTML para mostrar el contenido.

HTML significa HyperText Markup Language y se utiliza para organizar y describir el contenido de una página. En esta asignación se utiliza únicamente HTML, sin CSS ni JavaScript.

¿Qué es un sitio web?

Un sitio web es un conjunto de páginas web relacionadas entre sí y agrupadas bajo un mismo dominio. Por ejemplo, el sitio de una universidad puede tener páginas de admisión, carreras, noticias y contacto.

¿Qué es una aplicación web?

Una aplicación web permite realizar tareas e interactuar con datos, por ejemplo, registrar usuarios, enviar formularios o consultar información personalizada. Puede utilizar tecnologías adicionales en el servidor o en el navegador.

Diferencia entre sitio web y aplicación web

Un sitio web suele centrarse en presentar información para su consulta. Una aplicación web se enfoca en permitir acciones y procesos interactivos. Sin embargo, un mismo proyecto puede combinar características de ambos.

Tipos de páginas web

Páginas estáticas

Presentan contenido que permanece igual hasta que alguien modifica directamente los archivos. Son útiles para portafolios sencillos, páginas informativas y documentación básica.

Páginas dinámicas

Su contenido puede cambiar según las acciones del usuario, la información almacenada o las solicitudes realizadas. A menudo se conectan con bases de datos y utilizan tecnologías de servidor.
